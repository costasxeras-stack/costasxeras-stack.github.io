Garage Quote Agent

Small car repair garages lose customers because nobody answers "how much?" while the mechanics are under a car. This n8n automation answers price requests from WhatsApp, a web form or a webhook. AI reads the message, the garage's own price book sets the price, and the owner approves anything unclear from their own WhatsApp.

The question

How much of a garage's first reply to a price request can be automated safely, and where must the owner stay in control?

Approach

  • Split the problem in two. Understanding a message in free text is a job for AI. Pricing it is a job for rules the owner controls.
  • Put a confidence gate between them. The agent answers on its own only when every check passes. Otherwise it asks the owner, with the reasons.
  • Start with WhatsApp, because that is where customers already message garages.
  • Record every lead, routing decision and owner decision, so the garage can see where leads are lost.

Findings so far

Confirmed in testing

Uncertain requests go to the owner instead of a guess

Vague messages ("strange noise when I turn"), possible safety issues (smoke) and jobs only the owner can price (timing belt) all went to the owner with the reasons listed. Routine jobs with a known car were answered automatically.

Confirmed by design

Messaging rules shape the product

WhatsApp allows free replies only within 24 hours of the customer's last message. So the follow up is scheduled inside that window, and owner alerts depend on the owner keeping their own window open.

Hypothesis

"Not in the price book" is a demand signal

The weekly report lists requests that matched no job. I expect these to show which services to price next.

Hypothesis

Most requests are routine enough to answer automatically

To be measured in a pilot with a real garage.

23 of 23 test scenarios passed in n8n with sample data and test versions of the services. No real garage has used it yet.

What I would do next

  • Ask the customer a clarifying question when the car is missing, instead of sending it to the owner.
  • Approved WhatsApp templates for reminders after 24 hours.
  • Replies in Greek.
  • Calendar slots in the booking form.
  • A test set of real, anonymised messages to tune the confidence threshold.
